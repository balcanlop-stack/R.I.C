# R.I.C. - Registro Integral de Calificaciones

## Descripción

R.I.C. es un sistema de escritorio desarrollado para
facilitar la administración de calificaciones,
asistencia y seguimiento académico de los alumnos.

## Tecnologías

- Java 25
- JavaFX
- Scene Builder
- Maven
- MySQL
- JDBC

## Equipo de desarrollo

Proyecto integrador realizado por cinco integrantes.

## Estructura

- controller: controladores JavaFX.
- model: clases del sistema.
- dao: acceso a datos.
- service: lógica de negocio.
- database: conexión con MySQL.
- resources/fxml: interfaces.
- resources/css: estilos.
- resources/images: imágenes.
